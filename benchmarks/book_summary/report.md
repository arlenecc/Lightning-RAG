# Qwen3.5-0.8B vs 2B：电子书长章节总结能力对比

## 结论摘要

- **速度：0.8B 明显更快。** 端到端总耗时 128.58s，2B 为 231.25s，约 **1.8×**；平均 TTFT 27.0s vs 54.85s，约 **2.0×**；prefill / decode 吞吐分别约为 2B 的 **2.0× / 1.9×**。
- **质量：2B 明显更稳。** 人工复核后的五维综合均分：**0.8B 2.26 / 5，2B 3.55 / 5**。
- **0.8B 不适合 unsupervised 的长文本总结。** 三章中有一章（约 13k prompt tokens）触发重复循环，输出 18 次相同要点并在 1000 token 处被截断；另外两章格式完整，但覆盖浅，且各有明确事实错误。
- **2B 也会出错。** 第二章出现“案达罗为贵霜所灭”“茂斯王造塔”等多处事实/归属错误，仍必须人工审校。
- **4B 评审模型不能作为唯一裁判。** 它能提供有用线索，但误报率高、存在顺序偏差，且会漏掉真实错误。最终结论采用“4B 线索 + 人工对照原文复核 + 确定性指标”。

## 3. 质量评估方法

### 3.1 参考要点

对每章建立 8 条关键事实清单（`results/reference.json`）：

- 第一、二章：由 4B 提取，人工抽查修正。
- 第三章：4B 提取时出现重复/JSON 畸形，改为人工依据原文编写。
- 清单只用于“覆盖度”核对，不作为唯一事实标准；事实判断最终回到原文。

### 3.2 五维评分

| 维度 | 权重 | 说明 |
|---|---:|---|
| 事实准确性 | 40% | 5=无实质错误；4=仅轻微不精确；3=1 处实质错误；2=多处实质错误；1=普遍编造 |
| 内容覆盖 | 30% | 按 8 条参考要点计，完整覆盖=1，部分覆盖=0.5，未覆盖=0；映射到 5 分制 |
| 结构表达 | 15% | 章节完整、层次清楚、可读性 |
| 指令遵循 | 15% | 由 `analyze.py` 的确定性格式分（四部分、条数、关键词数、字数、重复/截断、前言） |
| 综合 | — | `0.4×准确性 + 0.3×覆盖 + 0.15×结构 + 0.15×指令` |

> 评分是人工复核分，不是 4B 打分。4B 的输出只用于发现问题线索。

### 3.3 4B 评审的使用方式

共做三类 4B 实验：

1. **匿名 A/B 评审**（`judge_test_013.json`）：第一章两轮均给两份摘要全 5 分、`winner=tie`，没有发现 0.8B 把“四圣谛”写错。
2. **逐点审计**（`audit_test_013.json`）：交换 A/B 顺序后，同一份 0.8B 摘要从“全部 covered”变成被列出 5 个错误，存在明显顺序偏差。
3. **逐句事实核查**（`factcheck.json`）：输入完整原文 + 8 条参考要点 + 单份摘要，输出 `issues`。

人工复核 4B 的 31 条 issues：

| 分类 | 数量 | 说明 |
|---|---:|---|
| 成立 | 10 | 与原文直接冲突或原文无依据 |
| 部分成立/过度严格 | 5 | 方向对，但理由或边界不准确 |
| 误报 | 16 | 原文有依据，4B 仍标 unsupported/contradicted |

即 **精确率约 32%**；同时至少漏掉 5 处真实错误（如 2B 的“八分教”“四涅槃”、部派名称年代地点错配等）。因此 4B 只能作为线索生成器。

### 4.3 分章要点

#### 第一章（教理，9,018 prompt tokens）

**0.8B：结构完整，但关键定义错误。**

- 把“四圣谛”写成 `（四谛、八正道、苦灭道、解脱）`。原文的四圣谛是苦、集、灭、道；八圣道是“道谛”的内容，不是四圣谛的并列组成项。这是明确的教理错误。
- `“法”与“行”互为表里，二者共同构成“三法印”`。原文是“诸法无我”与“诸行无常”互为表里，加上“一切行苦”为三法印；法与行有表里关系，但并非二者共同构成三法印。
- 遗漏第一结集/阿含经、法句经的理性性格、中道与四姓平等等内容；对五蕴、十二缘起只停留在名词层。
- 4B 把“三十七道品/四向四果”标为 unsupported，是误报，原文第 99–101 行明确有这两个概念。

**2B：覆盖最好，但仍有细节错误。**

- 覆盖第一结集/阿含经、四谛/渴爱、八圣道、中道、五蕴、法/缘起、十二缘起，八条中约 6.5 条有实质内容。
- 但把 `“以无明为缘而有行”` 说成“逆观”。原文这是**流转门/顺观**；“逆观”指“无明灭则行灭”的还灭门。
- 关键词“八分教”在原文中不存在，属于编造关键词。
- 结构上缺“本章结论”，关键词 8 个，汉字 340，指令分仅 3.00。

**结论：2B 明显更好；0.8B 虽通顺，但核心教理定义出错，不能直接用于知识性摘要。**

#### 第二章（阿育王以后的教团发展，12,976 prompt tokens）

**0.8B：灾难性失败。**

- 输出只有“一句话主旨 + 核心要点”两部分，第 3–20 条几乎完全相同：
  `佛塔建造者多为“贤胄部”成员，而“四方僧伽”主要居住于“僧院”中……`
  该句重复 18 次，在 1,000 token 处被截断；关键词、本章结论均缺失。
- 两个核心断言在原文中都无依据：
  - “佛塔与寺院由四方僧伽与贤胄部共同拥有，公元 2 世纪后所有权转移至贤胄部”
  - “佛塔建造者多为贤胄部成员，四方僧伽主要居住于僧院”
  原文只提到某些窟院/僧院布施给贤胄部、另一些布施给四方僧伽（如甘醯离第 70 窟与第 12/48/77/81 窟）；没有“共同拥有/所有权转移/建造者身份差异”的说法。
- 本章主要内容（熏迦、巴胡特、山齐、弥兰陀、塞迦、贵霜、德干窟院、部派碑文、大乘碑文）几乎全部缺失。

**2B：行文最完整，但事实错误最多。**

- 覆盖孔雀衰微/熏迦 112 年、弥兰陀、贵霜/迦腻色伽、部派碑文、大乘、佛塔艺术等，结构清楚，指令分 4.43。
- 明确错误：
  1. `案达罗王朝……后为贵霜王朝所灭`：原文说娑多婆诃王族在公元 3 世纪失势，德干进入诸族割据；贵霜在西北印度，并未灭案达罗。
  2. `部派教团之名最早见于公元 77 年（摩偷罗）及公元 2 世纪（北印度）`：原文是摩偷罗约公元 10 年、北印度公元 77 年，地点与年代被错配。
  3. `茂斯王征服北印度并建造佛塔`：造塔安奉舍利的是塞迦族牧伯波提迦；茂斯是塞迦首代王，未建此塔。
  4. `弥兰陀王（公元前 160—前 140 年在位）……撰写《弥兰陀王问经》`：年代不在原文中；“撰写”也不准确，原文是与龙军讨论、集其内容成经。
  5. `大乘佛教在贵霜王朝时期才在碑文中出现`：原文说“大乘”之语直到公元二三世纪仍未出现在碑文中。
  6. `案达罗王朝约持续 460 年`：原文说传说 460 年，但实际约 17–19 王、300 年；摘要把传说值当成事实。
- 4B 标为问题的“佛塔由砖石增广”“犍陀罗佛像受希腊影响”等，原文有依据，属于误报。

**结论：0.8B 在本章完全不可用；2B 结构好但事实密度高、错误多，必须逐条核验。**

#### 第三章（唯识的教理，16,991 prompt tokens）

**0.8B：能写出“像摘要”的文本，但概念关系错误、覆盖浅。**

- `佛陀识属“无”且无“无”`：原文明确说“佛陀的识是不含否定的有”，不是“无”。
- 把“识的转变”说成“种子生现行 + 异熟转变两种机制，前者连续性、后者断绝性”：原文说转变包含连续与断绝两个要因；果转变分为异熟、思量、了别境三种，并非这两种并列。
- 唯识二义表述含混；五重唯识只列了简称（遣虚、舍滥、摄末、隐劣、遣相），未说明“存实/留纯/归本/显胜/证性”，也未区分“五位”与“五重”。
- 完全未提阿赖耶识、种子赖耶/现行赖耶、阿陀那识、种子生现行/现行熏种子/种子生种子、三无性、三身/四身。
- 四智本身正确；4B 把四智标为 unsupported 是误报。

**2B：整体最扎实，但有 1 个编造概念和两处结构性遗漏。**

- 唯识二义、凡夫识/佛陀识、五重唯识观、阿赖耶识/阿陀那识、三性三无性、转依/四智均有覆盖，且多数与原文相符。
- 关键词和结论中出现 `四涅槃`：原文只有“大涅槃”，没有“四涅槃”，这是编造概念。
- 未覆盖识转变三义（异熟/思量/了别境）、种子生现行/熏种子/种子生种子、三身/四身。
- 未明确区分“五位”与“五重唯识观”；虽提到“资粮位至究竟位”，但没有说明二者不是同一层次。
- 4B 将本章 2B 的 6 条要点全部标为 unsupported，但原文逐条支持，属于严重误报。

**结论：2B 明显更可靠；0.8B 文字通顺但概念错误和遗漏都多，不能用于教理类内容。**

## 5. 4B 评审模型的表现与边界

### 5.1 有用之处

- 能生成可用的 8 条关键信息清单（第一、二章），为覆盖度评估提供起点。
- 逐句核查能抓到一些真实错误，例如：
  - 0.8B 第一章“四圣谛”组成错误；
  - 0.8B 第二章两条关于贤胄部/四方僧伽的编造；
  - 0.8B 第三章“佛陀识属无”；
  - 2B 第二章“案达罗为贵霜所灭”“茂斯王造塔”。

### 5.2 明显局限

1. **过于宽松 / 位置偏差**：第一章 A/B 两轮全 5 分、tie；交换顺序后同一份摘要的审计结果大幅变化。
2. **高误报率**：31 条 issues 中只有约 10 条完全成立，16 条为误报。典型误报：
   - 把 0.8B 的“三十七道品/四向四果”标为无依据（原文有）；
   - 把 0.8B 的“四智”标为无依据（原文有）；
   - 把 2B 第三章 6 条全部标为无依据，但原文逐条支持。
3. **漏报**：2B 的“八分教”“四涅槃”、部派名称年代地点错配、“大乘碑文”表述等均未被 4B 抓到。
4. **长上下文能力有限**：第三章 prompt 约 17.7k tokens，4B 对原文细节的定位明显下降；其自身 factcheck 单次耗时 157–255s、峰值显存 4.6–5.4 GB。
5. **tokenizer 警告**：加载 4B 时提示 Mistral regex 不匹配，建议 `fix_mistral_regex=True`；本次未影响 JSON 解析，但属于潜在风险。

**结论：4B 适合做“线索生成器/初筛器”，不适合做最终裁判。任何自动评分都必须配合原文人工复核。**

## 6. 0.8B 在长文本总结上的能力判断

### 6.1 它做对了什么

- 速度快：约为 2B 的 1.8× 端到端、2× TTFT。
- 能稳定输出 Markdown 四部分结构（三章中两章完整）。
- 语言通顺，能抓取部分表层主题（四谛、八正道、唯识、四智等）。
- 在 17k prompt tokens 下仍能完成生成，显存约 2.7 GB，没有 OOM。

### 6.2 它失败在哪里

- **重复循环**：第二章在 greedy、无 repetition penalty 的设置下，同一句重复 18 次，直到 `max_tokens` 截断。这不是提示词或 harness 错误，而是模型在长上下文下的真实退化模式。
- **事实错误**：四圣谛组成、佛陀识属性、识转变分类、法/行/三法印关系等，都是“读起来像那么回事”的错误。
- **覆盖浅**：长章节被压缩成 5 条左右的通识性陈述，关键人物、年代、因果链大量丢失。
- **指令遵循弱**：关键词数量、字数、结论段经常不达标；第二章直接丢掉两个部分。

### 6.3 适用边界

| 场景 | 是否适合 |
|---|---|
| 短文本/单段摘要、标题候选、关键词候选 | 可以，需轻量校验 |
| 低风险的阅读辅助、先扫一遍大意 | 可以，但不能当事实来源 |
| 13k+ tokens 的长章节一次性总结 | **不适合** |
| 教理、历史、人物年代等知识性摘要 | **不适合** |
| 无人审校的自动发布 | **不适合** |
| 作为 2B/更大模型的 draft 生成器 | 可以，但必须加重复惩罚/截断保护/事实校验 |

> 关键区别：0.8B 能生成“通顺的摘要文本”，但不能稳定生成“可靠的摘要内容”。在长文本总结任务上，这两者不是一回事。

---

## 7. 选型建议

1. **质量优先：选 2B。** 平均综合 3.55 vs 2.26；三章均未出现灾难性崩溃，长文覆盖和概念准确性明显更好。
2. **延迟优先：可以选 0.8B，但要改造流程。**
   - 不要一次性喂 13k+ tokens；改成按小节 chunk + map-reduce。
   - 加 repetition penalty / no-repeat n-gram / 重复检测熔断。
   - 强制结构校验（四部分、要点数、关键词数、字数），不合格重试或降级到 2B。
   - 关键事实必须由 2B/4B/人工复核，不能直接发布。
3. **2B 也不是“免审”模型。** 第二章的多处错误说明：流畅度和结构分高，不代表事实正确。建议对年代、人物、王朝归属、教理并列项做重点抽检。
4. **不要用 4B 单独当裁判。** 它的 A/B 评分过于宽松且有顺序偏差，逐句 factcheck 误报率高。合理做法是：4B 生成候选问题 → 人工对照原文裁决 → 只把确认项计入评分。
5. **如果业务允许更大模型：** 对知识性长文，优先用 4B 或更大模型做最终摘要，2B 做初稿/压缩，0.8B 只做极低成本的预处理。
